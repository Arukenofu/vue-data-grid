# Examples

<Description>
Complete grids, the way an app would build them: real data, real controls, several features
working together. Each page shows the live grid first, with its full source one switch away, then
walks through how it works.
</Description>

<ExampleGallery />

## How to read them

Every example is a component you could drop into an app. The grid itself comes from the parts and
composables of `@vue-data-grid/core`; the buttons, selects and badges come from the small kit these docs
use, which stands in for your own design system. When a piece of an example is new to you, the link
next to it leads to the guide that explains it.
